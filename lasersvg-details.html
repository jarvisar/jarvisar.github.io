Project Information

  • Name: laserSVG
  • Category: Blender Add-on
  • Output: SVG
  • GitHub Repo: github.com/jarvisar/laserSVG

About

A Blender add-on for creating city maps for laser engraving. Select an area, download the map from Overture Maps, and position a cutout in Blender. The exporter cleans up the geometry and separates roads, buildings, water, labels, and borders into SVG layers for Bambu Suite.
