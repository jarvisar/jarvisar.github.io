Geometric Pattern SVG Generator

  • Category: Generative Art / Pen Plotting
  • Built with: JavaScript, Canvas & SVG
  • Output: SVG with separate pen layers
  • GitHub Repo: github.com/jarvisar/geometric
  • Try it: ajarvis.co/geometric

Built for my pen plotter

I built this as a way to generate geometric line art for my pen plotter. Everything runs in the browser, with 25 different designs including spirographs, nested flowers, flowing fields, rosettes, geometric tiles, and more.

You can pick a pattern and tweak its settings, or randomize it to come up with something new. There are also controls for paper size, margins, and pen width so you can get a good idea of how the final plot will look before exporting it.

The SVG export is set up specifically for plotting, using millimeter dimensions and separate layers for each pen. It also clips everything to the page margins and tries to join and order paths to cut down on unnecessary pen movement.

Patterns use a seed, so if you find a variation you like, you can recreate it later. You can also save recipes or share a link to a specific setup.
